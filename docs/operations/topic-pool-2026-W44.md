- 发布脚本：`node scripts/publish-due-posts.mjs`（由 `.github/workflows/daily-publish.yml` 定时触发）

## 使用方式

1. 每天抓取微博热搜、B站热门、知乎热榜、抖音/百度热搜各前 20 条。
2. 按下方「硬性红线」剔除，再按栏目分配，填入表格。
3. 写稿完成后把 `选题` 列填上文章文件名（`YYYY-MM-DD-HHmm-slug.md`），全部 `draft: true`。
4. 发布脚本只认 `draft: true` 且 `published` 已到期的文章，按 `published` 升序取当批数量。

## 硬性红线（任一命中即弃稿）

政治/宗教/民族/地域对立、灾难伤亡、涉未成年人、未核实爆料、人身攻击与歧视、违法与盗版教程、色情擦边、直接搬运他人图文。
