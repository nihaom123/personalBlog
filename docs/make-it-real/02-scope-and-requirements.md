# 范围与需求

- **项目**: 温水煮冷水博客运营
- **类型**: content
- **生成时间**: 2026-10-23 19:15 +0800
- **文档作用**: 定义完整愿景、已选择的交付目标、当前交付范围、需求和暂不做事项。

## 完整愿景

让「温水煮冷水」成为一个持续更新、有人评论、有固定栏目的个人内容站，具备：

- 稳定日更节奏与四栏目结构；
- 内容生产半自动化（接模型 API 后全自动）；
- 读者可订阅、可评论、可分享；
- 数据可读（访问量、热门文章、评论来源）；
- 可按周复盘调整，而无需改代码结构。

## 已选择的交付目标

**一周试运行版本（V1 试运行）**：跑通「草稿 → 定时发布 → 构建上线 → 读者互动 → 数据回收」的完整闭环，连续 7 天每天 10 篇。

## 当前交付范围

**范围内**

1. 草稿与发布分离的内容目录与 frontmatter 规范。
2. GitHub Actions 每日定时发布（早 3 / 中 4 / 晚 3）。
3. 四栏目（热点搞怪、生活随笔、技术折腾、二次元）在站内正确归类与导航。
4. Waline 评论后端（Cloudflare Worker + D1）+ 前端接入。
5. Cloudflare Web Analytics 接入。
6. 首周 70 篇稿件生产（手动，无 API Key）。
7. 一周复盘与节奏调整结论。

**范围外（本阶段明确不做）**

- 内容自动生成（模型 API 接入）；
- 多作者/投稿系统；
-  Newsletter、会员、付费内容；
- 站内广告与商业化；
- 移动端 App、小程序；
- 自建数据库存储业务数据（评论除外）。

### 硬性红线（任一命中即弃稿）

1. 政治、宗教、民族、地域对立话题；
2. 灾难、事故、伤亡、疾病与医疗断言；
3. 涉未成年人、校园暴力、隐私泄露；
4. 未核实的爆料、传闻、人肉、指名道姓的负面评价；
5. 人身攻击、性别/外貌羞辱、歧视性玩笑；
6. 违法、赌博、诈骗、破解与盗版教程；
7. 色情擦边与低俗暗示；
8. 直接搬运他人图文（含热搜原文段落、他人梗图未授权）。

## 质量预期

- 语言：口语化、有梗但不油腻，不用「家人们」「~」结尾刷屏。
- 结构：开头 2 句内给出话题结论或冲突点；中段 1–3 个小标题；结尾一句互动提问。
- 事实：涉及数据、时间、人物时必须可溯源；不确定就写成「据公开报道」，宁可删。
- 排版：小标题 + 列表 + 必要配图（无图也能读），不整段加粗，不堆 emoji。
- 每篇必须有自己的观点或吐槽角度，不能是热搜复述。

## 当前范围暂不做事项

- 友链交换（先积累内容再谈）；
- 专题合集页与年度盘点；
- 多语言内容（仅中文）；
- 内容分发到公众号/小红书等外部平台（试运行后再评估）。

## 风险

见 [00-project-blueprint.md](00-project-blueprint.md#关键风险与假设)，补充：
