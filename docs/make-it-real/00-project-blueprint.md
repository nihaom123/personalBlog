# 项目总览

- **项目**: 温水煮冷水博客运营
- **类型**: content
- **生成时间**: 2026-10-23 19:15 +0800
- **文档作用**: 用于快速回顾项目并作为交接入口。

## 项目名称

温水煮冷水（https://05221024.xyz）—— 个人博客内容运营

## 一句话总结

在已完成个性化改造与 Cloudflare 部署的 Firefly 博客上，以「全托管运营、博主只审核」的方式，每天产出 10 篇搞怪向内容，用一周试运行验证读者反馈。

## 项目类型

内容运营（内容生产 + 自动化发布 + 社区互动），非新建软件项目。技术载体是已上线的 Astro + Firefly 静态博客。

## 目标用户或受众

- **主要读者**：喜欢轻松搞怪内容、有二次元/技术/生活兴趣的年轻网民，多为从热搜话题、搜索引擎、友链或社交分享进入的陌生人。
- **次要读者**：博主（阿胜）本人及熟人朋友，回看站点与留言互动。
- **博主角色**：唯一的审核者与最终责任人，不做日常产出。

## 核心问题或机会

- 问题：站点已上线但内容几乎为零，只有占位文章，无法形成访问理由与互动。
- 机会：搞怪向轻内容 + 高时效热搜话题，能以低创作成本获取搜索与社交传播的长尾流量；四栏目混排让站点同时具备「可读」与「可逛」。

## 核心价值

1. 对读者：一个每天有新东西、语气轻松、能留言吐槽的地方。
2. 对博主：几乎零日常投入，但站点持续更新、有活人感。
3. 对运营：内容生产与发布解耦，可随时按周调整节奏而不改代码。

## 完整愿景

把「温水煮冷水」做成一个有固定栏目、固定节奏、有人愿意在评论区聊天的小型个人内容站；后续可扩展友链互换、专题合集、年度盘点、周边梗图，乃至把高互动栏目做成独立专题页。

## 已选择的交付目标

**一周试运行版本（V1 试运行）**：用 7 天 × 10 篇的真实更新，验证「搞怪热搜 + 混合栏目」是否带来阅读与评论；一周后按数据决定是否调整频率、栏目权重与内容比例。

## 当前交付范围摘要

- 内容：四栏目（热点搞怪 / 生活随笔 / 技术折腾 / 二次元），每天 10 篇，早中晚 3/4/3 三批。
- 来源：微博热搜、B站热门、知乎热榜、抖音/百度热搜，二次加工为搞怪短文，禁止直接搬运。
- 发布：GitHub Actions 定时任务每日自动发布已就绪的稿件，博主抽检。
- 互动：Waline 评论（Cloudflare Workers + D1）。
- 统计：Cloudflare Web Analytics。
- 内容生产：先手动（无模型 API Key），按周批量产出 70 篇草稿。

## 推荐方案

草稿与发布分离：所有稿件先以 `draft: true` 落在 `src/content/posts/`，由定时任务按批次把当批稿件的 `draft` 翻转为 `false` 并提交触发 Cloudflare 构建；发布节奏由一份排期清单控制，改节奏只需改清单与任务配置，不动页面代码。

## 关键风险与假设

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 每天 10 篇产量过高，质量下滑 | 读者流失、内容同质 | 试运行一周后按数据下调；优先保「热点搞怪」质量 |
| 热搜话题涉及敏感内容 | 合规风险、账号风险 | 硬性红线清单 + 发布前抽检 |
| 直接搬运导致版权/原创度问题 | 投诉、SEO 降权 | 只取话题与角度，正文必须重写，不复制原文段落 |
| 定时发布无人看管 | 错误内容上线 | 抽检机制 + 一键回滚（git revert 或改回 draft） |
| 无模型 API，产量依赖人工 | 难以持续 | 试运行阶段先接受；后续接模型 API 自动化 |
| 站点无备案/无版权声明 | 内容被转载 | 站内声明、文末署名 |
